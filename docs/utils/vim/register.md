# register

可以把寄存器理解成 Vim 里的多个“剪贴板”。

---

#  默认寄存器 `"`

最常用。

复制：

```text
yy
```

复制后内容会进入默认寄存器：

```text
"
```

例如：

```text
yy
```

然后查看：

```vim
:reg "
```

---
---

# 命名寄存器

你可以自己保存内容：

```text
"ay
```

意思：

```text
a 寄存器
+
yank
```

例如复制一个单词：

```text
"ayiw
```

解释：

```text
"a      使用 a 寄存器
yiw     yank inner word
```

内容保存到：

```text
寄存器 a
```

之后可以随时粘贴：

```text
"ap
```

# 4. 删除内容时不要污染复制内容


假设你复制：hello

然后：

```text
vi(
```

选中：

```text
old content
```

如果直接：

```text
d
```

那么：

```text
old content
```

可能进入默认寄存器。

你的：

```text
hello
```

就没了。

---

## 使用黑洞寄存器 `"_`

删除但不保存：

```text
"_d
```

例如：

```text
vi(
"_d
```

这样：

```text
()
```

里面内容被删除。

但是你之前复制的内容：

```text
"
```

仍然保持：

```text
hello
```

然后：

```text
p
```

就可以粘贴。

完整操作：

```text
vi("_dp
```

不过这个写法要注意操作顺序。

#  常用寄存器

| 寄存器   | 作用        |
| ----- | --------- |
| `"`   | 默认寄存器     |
| `0`   | 最近一次 yank |
| `-`   | 小删除寄存器    |
| `a-z` | 自定义寄存器    |
| `+`   | 系统剪贴板     |
| `_`   | 黑洞寄存器     |
| `:`   | 最近执行的命令   |
| `/`   | 最近搜索内容    |
